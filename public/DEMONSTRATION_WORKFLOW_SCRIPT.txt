2. ACT 1: INSTRUMENT OWNER WORKFLOW (COMMERCIAL APPLICANT)
================================================================================

SCENE OBJECTIVE:
Demonstrate how a commercial trader or industrial plant manager registers a newly
acquired or existing machine, captures exact machine GPS coordinates using the device
sensors, submits statutory compliance documents, and tracks digital verification.

STEP 1.1: Persona Selection & Compliance Overview
------------------------------------------------
- In the top navigation bar, click the Role Switcher and select "Applicant - Ramesh Patel".
- Navigate to the Applicant Dashboard (/applicant).
- Demonstration Points:
  * Compliance Status Cards: Review the high-level counters:
    - Total Registered Instruments (e.g. 5 assets)
    - Active Stamped Certificates (e.g. 4 valid units)
    - Expiring Soon in 30 Days (amber alert for timely re-verification)
    - Critical Non-Compliant / Expired Units (red indicator)

    seizure liabilities under the Legal Metrology Act, 2009 for using unstamped units.
  * Live Application Timeline: Displays real-time progress of submitted requests
    (Submitted -> Scheduled -> In Progress -> Verified / Rejected).

STEP 1.2: Onboarding an Instrument with Exact GPS Coordinates
-------------------------------------------------------------
- Click the primary action button: "+ Register Instrument & Apply".
- The "Register Instrument & Apply for Verification" modal opens.
- Demonstration Steps:
  1. Select Mode: Choose "New Instrument Onboarding".
  2. Input Machine Specifications:
     - Instrument Type: Commercial Electronic Scale (or Weighbridge / Fuel Dispenser)
     - Make & Model: Essae-Teraoka DS-215 Electronic Bench Scale
     - Serial Number: ESS-2026-9941
     - Capacity & Verification Interval (e): 30 kg, e = 5 g
     - Accuracy Classification: Class III (Medium Accuracy - Commercial)
  3. Input Physical Installation & GIS Coordinates:
     - Premises / Site Address: Shop 18, Commercial Arcade, Inner Circle
     - Postal PIN Code: Enter "110001" (The built-in GIS engine automatically matches
       the postal code and pre-loads standard coordinates).
     - One-Click GPS Button: Click "📍 Use My Current Location".
       * The browser queries the device's HTML5 Geolocation API.
       * High-precision Latitude (e.g. 28.632845 N) and Longitude (e.g. 77.219520 E)
         are captured with instant accuracy feedback (e.g. "±8m accuracy").
  4. Select Application Type: Initial Verification (New) or Periodic Re-verification.
  5. Upload Statutory Documents & Photographs:
     - Upload stamped serial plate photograph.
     - Upload manufacturer invoice or model approval certificate.
     - Enter applicant notes: "New bench scale deployed at retail packing station."
  6. Click "Submit Application".
- Outcome:
  * The instrument is immediately written to the database with its exact coordinates.
  * A new application (e.g. APP-2026-013) is created and queued for inspector scheduling.

3. ACT 2: LEGAL METROLOGY OFFICER (LMO / FIELD INSPECTOR) WORKFLOW
================================================================================

SCENE OBJECTIVE:
Demonstrate how an authorized inspector manages verification queues, conducts
statutory on-site Rule 14 testing, calculates Maximum Permissible Errors (MPE),
issues cryptographically sealed digital certificates, and conducts GIS raid planning.

STEP 2.1: Inspector Persona & Command Center Overview
-----------------------------------------------------
- In the top navigation bar, switch role to "LMO - S. K. Sharma".
- Navigate to the Officer Command Center (/officer).
- Demonstration Points:
  * Inspection Metrics: Applications in queue, inspections scheduled today,
    certificates stamped this month, and seizure notices served.
  * Statutory Pendency Tracking: Monitors applications approaching the 48-hour SLA
    stipulated under Rule 14 of the Legal Metrology Rules.

STEP 2.2: Scheduling and Conducting Technical Verification (/queue)
-------------------------------------------------------------------
- Navigate to the "Verification Queue" tab.
- Demonstration Steps:
  1. Review pending applications awaiting verification.
  2. Select an application (e.g. APP-2026-003 or APP-2026-004).
  3. Inspection Scheduling:
     - Click "Schedule Inspection".
     - Pick an inspection date and appointment time.
     - Assign to self or route to GATC testing lab if it requires precision calibration.
  4. Conducting Technical Verification (Rule 14 Verification Modal):
     - Click "Verify & Stamp Instrument".
     - Technical Checklist & Tolerance Protocol:
       * Check 1: Visual Inspection & Model Approval Verification passed.
       * Check 2: Physical Seal & Stamping Plate Integrity verified.
       * Check 3: Load Point Testing (Recorded at Zero, 1/4, 1/2, and Full Capacity).
       * Check 4: Maximum Permissible Error (MPE) Validation:
         Recorded error (+0.002 kg) is within permissible legal limit (±0.005 kg).
       * Check 5: Security Seal Affiliation: Enter physical lead/wire seal tag ID
         (e.g. SEAL-DL-2026-8812) and fee receipt number (REC-2026-9921).
     - Select Final Determination: "PASS (Approved for Stamping)".
     - Click "Issue Certificate".
- Outcome:
  * The application status instantly updates to "verified".
  * A digital certificate with a QR code and statutory validity window is generated.
  * The instrument record in the registry updates its expiration date automatically.

STEP 2.3: GIS Enforcement Map & Unannounced Raid Planning (/gis-map)
--------------------------------------------------------------------
- Click on the "Enforcement Map" tab in the sidebar.
- Scenario: Conducting targeted market surveillance in Connaught Place (110001).
- Demonstration Steps:
  1. In the search filter bar, enter PIN Code: "110001".
  2. Set the Enforcement Radius slider to: "5 km".
  3. Filter by Compliance Status: Select "Expired Only (Critical)".
  4. Map Intelligence Analysis:
     * The map centers dynamically on Central Delhi with a high-contrast circular radius.
     * Red pulsing alert markers identify non-compliant commercial assets:
       - Marker 1: Chawla Bullion & Gems Jewellers (Lat: 28.6328, Lng: 77.2195).
         Mettler Toledo Bullion Balance expired on 27 Feb 2025 (Distance: 0.32 km).
       - Marker 2: Janpath Commercial Fuels & Logistics (Lat: 28.6291, Lng: 77.2180).
         Wayne Dual Fuel Dispenser expired on 14 Mar 2025 (Distance: 0.45 km).
  5. Establishment Drawer & Raid Dispatch:
     * Click on Chawla Bullion on the map.
     * The Establishment Enforcement Drawer slides open, displaying business owner
       contact, exact serial number, last certificate reference, and statutory fine exposure.
     * Click "Schedule Raid / Inspection": Instantly creates a priority unannounced
       enforcement case under Section 24 of the Legal Metrology Act, dispatching the case
       directly into the officer's inspection queue.

4. ACT 3: GATC TEST CENTER STAFF (NABL CALIBRATION LAB) WORKFLOW
================================================================================

SCENE OBJECTIVE:
Demonstrate the specialized workflow for laboratory-certified precision instruments
requiring environmentally controlled metrological testing (Class I balances, grain moisture
analyzers, and bulk flow standards).

STEP 3.1: GATC Persona & Specialized Queue
------------------------------------------
- In the top navigation bar, switch role to "GATC - Dr. Ananya Sen".
- Navigate to the Calibration Queue (/queue).
- Demonstration Points:
  * The queue filters high-accuracy instruments routed by state inspectors for laboratory
    testing (e.g. Dickey-John GAC 2500-UGMA Grain Moisture Analyzer or Sartorius Class I Micro-balance).

STEP 3.2: Laboratory Calibration & Metrological Testing Protocol
----------------------------------------------------------------
- Select the assigned GATC application and open the Calibration Protocol.
- Demonstration Steps:
  1. Environmental Chamber Controls:
     - Record chamber ambient temperature (20.0 C ± 0.5 C).
     - Record relative humidity (50% ± 5%) and barometric pressure (1013.2 hPa).
  2. NPL Standards Traceability:
     - Verify reference standard mass set against primary national standards
       from the National Physical Laboratory (NPL India).
  3. Metrological Test Sequences:
     - Repeatability test (10 consecutive weighings at nominal load).
     - Eccentric loading test (quadrant deviation analysis).
     - Linearity test across full working envelope.
  4. Measurement Uncertainty Calculation:
     - Expanded uncertainty evaluation: U = 0.02 mg (coverage factor k = 2).
  5. Issue Calibration Report:
     - Mark report as "Compliant with OIML R-76 / IS-9281".
     - Click "Complete Lab Verification".
- Outcome:
  * The NABL calibration certificate is permanently linked to the instrument dossier.
  * The state Legal Metrology Department receives the clearance for final stamping release.
